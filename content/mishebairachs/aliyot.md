# Aliyot / עליות

::: prayer
מִי שֶׁבֵּרַךְ אֲבוֹתֵינוּ אַבְרָהָם יִצְחָק וְיַעֲקֹב מֹשֶׁה וְאַהֲרֹן דָּוִד וּשְׁלֹמֹה, הוּא יְבָרֵךְ אֶת [שֵׁם] בֶּן/בַּת [שֵׁם הָאָב]
בַּעֲבוּר שֶׁעָלָה לַתּוֹרָה לִכְבוֹד הַמָּקוֹם לִכְבוֹד הַתּוֹרָה

::: prayer-shabbat
בשבת: וְלִכְבוֹד הַשַּׁבָּת
:::

::: prayer-chaggim
ביו"ט וחוה"מ: וְלִכְבוֹד הָרֶגֶל
:::

::: prayer-high-holidays
בר"ה: וְלִכְבוֹד יוֹם הַדִּין
:::

::: prayer-high-holidays
ביוה"כ: וְלִכְבוֹד יוֹם הַכִּפּוּרִים
:::

בִּשְׂכַר זֶה הַקָּדוֹשׁ בָּרוּךְ הוּא יִשְׁמְרֵהוּ וְיַצִּילֵהוּ מִכָּל צָרָה וְצוּקָה וּמִכָּל נֶגַע וּמַחֲלָה וְיִשְׁלַח בְּרָכָה וְהַצְלָחָה בְּכָל מַעֲשֵׂה יָדָיו

::: prayer-chaggim
ביו"ט: וְיִזְכֶּה לַעֲלוֹת לָרֶגֶל
:::

::: prayer-high-holidays
בר"ה ויוה"כ: וְיִכָּתֵב וְיֵחָתֵם לְחַיִּים טוֹבִים בְּיוֹם הַדִּין הַזֶּה
:::

עִם כָּל יִשְׂרָאֵל אֶחָיו וְנֹאמַר אָמֵן
:::
