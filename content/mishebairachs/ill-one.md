# מי שברך לחולה אחד

## לזכר (for a male patient)

::: prayer
מִי שֶׁבֵּרַךְ אֲבוֹתֵינוּ אַבְרָהָם יִצְחָק וְיַעֲקֹב מֹשֶׁה וְאַהֲרֹן דָּוִד וּשְׁלֹמֹה,
הוּא יְבָרֵךְ וִירַפֵּא אֶת הַחוֹלֶה [שֵׁם] בֶּן [שֵׁם הָאֵם]
בַּעֲבוּר שֶׁ[שֵׁם הַנּוֹדֵר] יִתֵּן צְדָקָה בַּעֲבוּרוֹ.
בִּשְׂכַר זֶה הַקָּדוֹשׁ בָּרוּךְ הוּא יִמָּלֵא רַחֲמִים עָלָיו
לְהַחֲלִימוֹ וּלְרַפְּאוֹתוֹ וּלְהַחֲזִיקוֹ וּלְהַחֲיוֹתוֹ,
וְיִשְׁלַח לוֹ מְהֵרָה רְפוּאָה שְׁלֵמָה מִן הַשָּׁמַיִם לִרְמַ״ח אֵבָרָיו וּשְׁסָ״ה גִּידָיו,
בְּתוֹךְ שְׁאָר חוֹלֵי יִשְׂרָאֵל, רְפוּאַת הַנֶּפֶשׁ וּרְפוּאַת הַגּוּף,

::: prayer-shabbat
בשבת: שַׁבָּת הִיא מִלִּזְעֹק וּרְפוּאָה קְרוֹבָה לָבוֹא,
:::

::: prayer-chaggim
ביו"ט: יוֹם טוֹב הוּא מִלִּזְעֹק וּרְפוּאָה קְרוֹבָה לָבוֹא,
:::

::: prayer-shabbat-chaggim
בשבת ויו"ט: שַׁבָּת וְיוֹם טוֹב הֵם מִלִּזְעֹק וּרְפוּאָה קְרוֹבָה לָבוֹא,
:::

הַשְׁתָּא בַּעֲגָלָא וּבִזְמַן קָרִיב, וְנֹאמַר אָמֵן.
:::

## לנקבה (for a female patient)

::: prayer
מִי שֶׁבֵּרַךְ אֲבוֹתֵינוּ אַבְרָהָם יִצְחָק וְיַעֲקֹב מֹשֶׁה וְאַהֲרֹן דָּוִד וּשְׁלֹמֹה,
הוּא יְבָרֵךְ וִירַפֵּא אֶת הַחוֹלָה [שֵׁם] בַּת [שֵׁם הָאֵם]
בַּעֲבוּר שֶׁ[שֵׁם הַנּוֹדֵר] יִתֵּן צְדָקָה בַּעֲבוּרָהּ.
בִּשְׂכַר זֶה הַקָּדוֹשׁ בָּרוּךְ הוּא יִמָּלֵא רַחֲמִים עָלֶיהָ
לְהַחֲלִימָהּ וּלְרַפְּאוֹתָהּ וּלְהַחֲזִיקָהּ וּלְהַחֲיוֹתָהּ,
וְיִשְׁלַח לָהּ מְהֵרָה רְפוּאָה שְׁלֵמָה מִן הַשָּׁמַיִם לְכָל אֵבָרֶיהָ וּלְכָל גִּידֶיהָ,
בְּתוֹךְ שְׁאָר חוֹלֵי יִשְׂרָאֵל, רְפוּאַת הַנֶּפֶשׁ וּרְפוּאַת הַגּוּף,

:::

::: prayer-chaggim
